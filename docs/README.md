# OctoAcme Project Management Docs

Welcome! This README introduces OctoAcme’s project management processes and provides links to the core documentation located in this repository's docs/ folder.

## Project management overview (brief)
OctoAcme uses a structured, iterative approach focused on delivering shippable value with clear ownership and continuous improvement:

- Initiation: Define the problem, identify stakeholders, set timelines and success metrics, and confirm scope.
- Planning: Break initiatives into shippable increments, identify dependencies, create milestones, and estimate work.
- Execution & Tracking: Use project boards and sprint-style increments, run standups, track progress against milestones, and perform quality checks.
- Risk Management: Maintain a visible risk register, track mitigation actions, and use clear escalation paths.
- Release & Deployment: Coordinate releases with checklists, pre-release validation, communication plans and rollback procedures.
- Retrospectives & Continuous Improvement: Run retrospectives to capture learnings, assign action items, and iterate on process improvements.
- Roles & Personas: Clearly define responsibilities for Product Management (PdM), Project Management (PM), Developers, QA, and Stakeholders.

This README is an entry point to the full process docs and is intended to help new team members quickly understand how we run projects at OctoAcme.
